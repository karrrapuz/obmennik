# GRAM Display

The native coin is displayed as GRAM, formerly Toncoin/TON. This is a name change,
not an exchange or balance conversion. Internal `DEMO_TON`, nano amounts and
integration identifiers remain unchanged for API and stored-data compatibility.

The Gram diamond mark in `src/assets/gram.svg` is from the official token assets:
https://ton.org/media/ (https://ton.org/assets/media/gram_diamond_mark.zip).
The TON network keeps its name. No Portals pricing connection is enabled by this
display-only update; presentation prices are still presentation prices.

GiftRelayer currently opens https://t.me/smekz. Opening this link neither transfers
a gift nor credits inventory. Actual custody reconciliation requires a separate
backend integration.
