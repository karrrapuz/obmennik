# Локальный каталог через Telethon

Этот инструмент запускается отдельно от API. Он не подключается к открытому
Telegram Desktop и не использует его сессию. Вход выполняет пользователь
в собственном интерактивном терминале. Личная сессия не отправляется на хостинг.

## Подготовка

Установить backend/requirements-telegram.txt в локальную backend/.venv.
В backend/.env.telegram заполнить TELEGRAM_API_ID и TELEGRAM_API_HASH.
Шаблон полей: backend/telegram.credentials.example. Номер телефона, код и
пароль 2FA в этот файл не записывать. Не пересылать ключи, коды или сессию
в чат, Git, логи и архивы для передачи проекта.

```powershell
backend/.venv/Scripts/python.exe backend/scripts/telegram_catalog.py check-config
backend/.venv/Scripts/python.exe backend/scripts/telegram_catalog.py login
backend/.venv/Scripts/python.exe backend/scripts/telegram_catalog.py qr-login
backend/.venv/Scripts/python.exe backend/scripts/telegram_catalog.py status
backend/.venv/Scripts/python.exe backend/scripts/telegram_catalog.py preview
```

На Windows вход также запускается через backend/scripts/telegram_login.ps1.
qr-login открывает локальную HTML-страницу с QR, обновляет токен после истечения
и ждёт до пяти минут. В Telegram на телефоне: Настройки → Устройства →
Подключить устройство. QR не отправляется во внешние генераторы и чат;
страница удаляется после завершения или ошибки. При 2FA пароль вводится в
терминале. Не запускать два входа одновременно с одним session-файлом.
Телефон вводится видимо для проверки формата; код и пароль вводятся скрыто.
Не отправлять скриншоты с номером телефона. Скрипт не выводит данные профиля.
Скрипт не запускает новый вход автоматически; Telethon допускает ограниченные
повторы RPC, необходимые в том числе для перенаправления между датацентрами.
При FloodWait нужно дождаться
указанного Telegram времени, а не запускать повторные попытки подряд.

## Импорт

```powershell
backend/.venv/Scripts/python.exe backend/scripts/telegram_import.py --base-only
backend/.venv/Scripts/python.exe backend/scripts/telegram_import.py
```

Первый проход сохраняет базовые типы и изображения; полный проход также читает
GetStarGiftUpgradeAttributes и загружает доступные модели, символы и фоны.
Повторный запуск продолжает импорт с сохранённых данных. Флаг --refresh
повторно читает атрибуты существующих коллекций и проверяет их кэш изображений,
сохраняя внутренние ID. Не запускать два
импорта одновременно. При ограничении Telegram прогресс сохраняется.
Полный импорт с ошибками завершается ненулевым кодом; готовность проверяется
по stats.complete, metadataComplete и missingMedia в манифесте.

Публичные данные: public/gifts/telegram/catalog.json и media/*.webp.
Копия метаданных API: backend/data/catalog-telegram.json. Сюда не входят
access_hash, file_reference, ключи или пользовательские данные.
Встроенные 20 примеров сохраняются, импортированные коллекции доступны для
просмотра и фильтров. Цена в Stars не конвертируется в выдуманную цену TON:
до отдельного рыночного источника обмен и займы для них отключены.

Сезонные примеры добавляются один раз на пользователя только в режиме demo.
Маркер выдачи переживает вывод подарка. Это не реальные подарки пользователя.
Год сезонной подборки берётся из first_sale_date Telegram, а не текущей даты.

## Ограничения

Скрипт использует только вход, проверку своей авторизации и чтение базового
каталога GetStarGifts и атрибутов GetStarGiftUpgradeAttributes. preview выводит
число типов подарков, а telegram_import.py экспортирует публичные изображения
и атрибуты. Рыночных цен Telegram эти команды не дают.
Сообщения, контакты, покупки, переводы и конвертация подарков не вызываются.
Кэш сущностей отключён. Только во время QR-входа разрешены обновления для
ожидания подтверждения авторизации; после входа они снова отключаются.

Важно: пользовательская Telegram-сессия сама по себе НЕ имеет ограниченного
read-only разрешения. Только этот код ограничен перечисленными действиями.
Файл backend/.local/telegram/catalog.session позволяет входить без нового
кода и должен храниться как секрет. Он и его служебные файлы исключены из Git.
Они также исключены из Docker-контекста на уровне корня и backend.
Для продажи проекта передаются только скрипты и шаблон, не личная сессия.

Документация: [вход Telethon](https://docs.telethon.dev/en/stable/basic/signing-in.html),
[защита сессий](https://docs.telethon.dev/en/stable/concepts/sessions.html).
