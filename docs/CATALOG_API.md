# Публичный каталог и атрибуты

Эти GET-маршруты не требуют входа, не создают пользователя и не изменяют
инвентарь, баланс или цены. Источник — локально импортированный каталог
Telegram, не личная сессия на сервере. Поля ответа перечислены явно:
владельцы, access_hash, file_reference и произвольные поля источника не выдаются.

| Маршрут | Результат |
| --- | --- |
| `/api/catalog` | Версия индекса, число коллекций и уникальных атрибутов |
| `/api/catalog/attributes?kind=models` | Варианты моделей; также `symbols`, `backdrops` |
| `/api/catalog/collections` | Коллекции, подходящие под комбинацию атрибутов |

Списки используют `q` (до 128 символов), `offset` и `limit` (1–100).
Ответ: `items`, `total`, `offset`, `limit`, `nextOffset`, `version`.
Заголовок `X-Catalog-Version` совпадает с версией данных. Общее правило
`Cache-Control: no-store` для API сохранено.

`collection_ids` — повторяемый параметр с Telegram ID коллекции строкой.
Для `/collections` доступны повторяемые `model_ids`, `symbol_ids`, `backdrop_ids`.
Внутри одного вида атрибутов действует OR, между видами и коллекцией — AND.
Неизвестные ID и чрезмерные запросы возвращают 422, несовместимые известные
атрибуты — пустую выдачу. Никакие варианты подарков в инвентаре не создаются.

Канонические значения фильтров:

- Модель: `tg:model:<telegramId>:<documentId>`.
- Символ: `tg:symbol:<documentId>`.
- Фон: `tg:backdrop:<backdropId>`.

Название — только подпись. Две модели с одинаковым названием из разных
коллекций остаются разными вариантами. Общие символы и фоны объединяются
по ID, а не по названию. Редкость общей опции не показывается, если в
коллекциях она различается. При выборе одной коллекции возвращается её редкость.

Фронтенд использует те же ключи и полный статический манифест как источник
фильтров, загружая ограниченные страницы вариантов в DOM. Старые текстовые
фильтры 20 демонстрационных образцов остаются совместимыми.

`public/gifts/telegram/labels.json` и `backend/data/catalog-labels.json` —
идентичные описательные имена для типов без официального sourceTitle.
Официальное имя всегда имеет приоритет. Подмена отображаемого имени не меняет
Telegram ID, внутренний catalogId, владение или финансовые ограничения.
Импорт использует этот же справочник при следующем обновлении.

`omittedAttributes` в сводке отмечает повреждённые или конфликтующие опции,
которые не попали в индекс. У проверенного полного снимка значение равно нулю.

ID коллекций и документов принимаются только как канонические положительные
signed-int64 строки без ведущих нулей; ID фонов ограничены signed-int32.
Каждый параметр проверяется по длине и формату до обращения к индексу.

Карточки импортированных типов содержат необязательное поле `presentation`:
`{kind: 'decorative', backdrop: {centerColor, edgeColor, patternColor, textColor}}`.
Это только оформление неизвестного фона, а не настоящий атрибут подарка.
Оно не участвует в фильтрах, расчёте цен, доступности обмена или залога.
Настоящие `backdrop` и `symbol` всегда имеют приоритет при отображении.
