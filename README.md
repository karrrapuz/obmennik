# GiftMoney: frontend

React 19 + TypeScript + Vite. Telegram Mini App: обмен подарков, залог и профиль.
Операции и баланс пока демонстрационные, сервера нет.

## Запуск

Node.js 22.12+ или совместимая актуальная LTS.

```sh
npm ci
npm run dev
npm run build
npm run preview
npm run lint
node scripts/check-gift-sample.mjs
```

Папка `dist/` после сборки готова для статического HTTPS-хостинга.
Исходники, а не dist и node_modules, хранятся в Git.

## Где что менять

| Папка / файл | Назначение |
| --- | --- |
| `src/main.tsx`, `src/App.tsx` | Точка входа, инициализация Telegram, загрузочный экран |
| `src/pages/HomePage/` | Переключение разделов, общий баланс, открытие пополнения |
| `src/components/layout/PageHeader/` | Общий хедер обмена и залога, баланс и плюсик |
| `src/components/layout/PageFooter/` | Нижняя навигация и её стили |
| `src/components/layout/AppShell/` | Внешний контейнер приложения |
| `src/components/gifts/GiftArtwork/` | Модель, фон и символ подарка |
| `src/components/feedback/SlideNotice/` | Анимация уведомлений |
| `src/hooks/` | Анимация баланса, блокировка прокрутки за модалкой |
| `src/styles/` | Глобальные стили, оболочка, общий эффект нажатия |
| `src/assets/` | Общие аватар, TON и плюсик |
| `src/services/telegram.ts` | Цвета Telegram, разворачивание, запрет свайпа сворачивания |
| `src/pages/ExchangePage/` | Обмен; styles разбиты по блокам, components содержит модалки |
| `src/pages/DepositPage/` | Залог, оформление, продление, информация о займе |
| `src/pages/ProfilePage/` | Профиль, пополнение, вывод, рефералка |
| `src/pages/LoadingPage/` | Стартовый экран |

| `scripts/` | Импорт и проверка демонстрационного каталога |

CSS компонента находится рядом с ним. Специфичные ассеты остаются рядом со
своей страницей. Старые имена классов общего хедера (`exchange-*`) сохранены
для совместимости. Хедер профиля намеренно другой и остаётся частью профиля.
Экспортированные SVG часто уже содержат свет и blur: не дублируйте эффекты.

## Подключение бэкенда

- `ExchangePage/services/giftRepository.ts`: демо-репозиторий обмена.
- `ExchangePage/data/gifts.ts` и `catalog-sample.json`: демо-каталог и фильтры.
- `DepositPage/services/pledgeStore.ts`: локальные займы и отдельный демо-баланс.
- `ProfilePage` и `ProfileModal`: локальные кошелёк, рефералка и платежи.
- Баланс профиля/обмена и баланс залога пока **не единый источник данных**.
- Инвентари разделов также требуют общего серверного источника.
- Состояние сбрасывается после перезагрузки; операции имитируются таймерами.
- Сервер должен проверять Telegram initData, владение подарками, суммы,
  комиссии и право на операцию. Клиентским ценам и флагам доверять нельзя.
- Bot token, api_hash и Telethon-сессии не должны попадать во фронтенд.

Линтер пока сообщает существующие предупреждения React по эффектам и refs.
Их исправление следует вести отдельно от структурного рефакторинга.

## Проверка интерфейса

Проверяйте обмен, фильтры, выбор подарков, профиль/рефералку, пополнение,
оформление/продление залога, раскрытие списков и закрытие модалок.
Мерцание и жесты Telegram дополнительно проверяются на настоящем iPhone:
успешная сборка не заменяет проверку WebView.
